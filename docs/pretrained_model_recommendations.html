Pretrained Model Recommendations

Pretrained Model Suggestions For MASI

Searched: 2026-05-12

This list is based on the current MASI training pipeline in docs/training_process_latest.md.

MASI model/component Suggested pretrained model(s) Notes
Frozen text + image encoder Marqo/marqo-fashionSigLIP Best first choice for Clothing/Shoes/Jewelry because it is fashion/e-commerce oriented.
Frozen text + image encoder, broader e-commerce Marqo/marqo-ecommerce-embeddings-B Good broader Amazon/e-commerce candidate. More practical than the larger model.
Frozen text + image encoder, larger e-commerce Marqo/marqo-ecommerce-embeddings-L Higher-capacity option, but likely heavier for Kaggle/runtime memory.
Conservative CLIP upgrade openai/clip-vit-large-patch14 Easiest CLIP-family upgrade from current openai/clip-vit-base-patch32.
Generic modern vision-language encoder google/siglip2-base-patch16-512 Strong generic image-text encoder, but less domain-specific than Marqo fashion/e-commerce models.
Text projection head No suitable standalone pretrained model found Should remain trained from scratch because it learns CSJ user-item behavior signals.
Vision projection head No suitable standalone pretrained model found Should remain trained from scratch for the same behavior-alignment reason.
Behavior-aware alignment model No direct pretrained drop-in found Keep local InfoNCE training over collaborative positive/negative pairs.
Text RQ-VAE / text codebooks Reference only: edobotta/rqvae-amazon-beauty Not a direct fit because it is Amazon Beauty/text-only and codebooks are embedding-dataset-specific.
Vision RQ-VAE / visual codebooks No suitable pretrained drop-in found Should be trained on MASI’s selected CSJ visual embeddings.
Cross-modal MLM Transformer Possible warm-start from BERT/T5, but not recommended first MASI’s SID vocabulary is generated per run, so pretrained language token embeddings do not transfer cleanly.
Autoregressive generative SID recommender References: kkknight/MiniOneRec, snap-research/GRID Useful as generative-recommendation references, not direct replacements for MASI’s late-fused SID recommender.
SASRec / sequential-rec baseline RUCAIBox/UniSRec Closest pretrained sequence-recommendation reference; better as a baseline/adaptation candidate than a MASI component.

Short Ranking

  1. Marqo/marqo-fashionSigLIP
  2. Marqo/marqo-ecommerce-embeddings-B
  3. openai/clip-vit-large-patch14
  4. google/siglip2-base-patch16-512
  5. Marqo/marqo-ecommerce-embeddings-L
